# Luxury Krown Studios — Vanilla JavaScript E-commerce

Open `index.html` in a browser. The project uses only HTML, CSS and vanilla JavaScript.

Pages: Home, Product Listing, Product Details, Cart, Checkout, About, Contact, Login/Signup.

Features: responsive hamburger navigation, dynamic product data, search/filter/sort, localStorage cart, quantity controls, wishlist, client-side validation, toast notifications, dark/light theme, testimonials/feature sections, and responsive layouts.

Product images use remote Unsplash URLs as placeholders; replace them with local files in `assets/` for a fully self-contained offline build.
